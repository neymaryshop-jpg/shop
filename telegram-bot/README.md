# 🎮 NeymaryShop Telegram Bot

Бот для продажи доната в игры с 3-этапной системой оплаты.

## 📋 Возможности

### 🎯 Основной функционал:
- **3 этапа оплаты**: Оплата → Почта → Код
- **Пополнение Steam** с кодами подтверждения
- **Промокоды** (только для Steam)
- **Пополнение из разных стран**: 🇷🇺🇺🇦🇰🇿🇺🇿🇹🇷🇺🇸🇪🇺
- **История заказов**
- **Профиль пользователя**
- **Поддержка 24/7**

### 🎮 Поддерживаемые игры:
- Steam
- Valorant
- CS2
- PUBG
- Genshin Impact
- Honkai Star Rail
- Arena Breakout
- Lost Light

### 💳 Способы оплаты:
- 💳 Банковская карта
- 📱 СБП
- ₿ Crypto (TON)
- 🏦 ЮMoney

## 🚀 Использование

### Команды:
- `/start` - Запустить бота
- `/admin-panel` - Админ панель (только для админов)

### Тестовые промокоды:
- `STEAM-FREE-100` - 100₽
- `STEAM-BONUS-50` - 50₽
- `STEAM-START-200` - 200₽
- `WELCOME-150` - 150₽
- `GIFT-300` - 300₽

## 📦 Процесс покупки

1. **Выбор игры** → Пользователь выбирает игру
2. **Выбор суммы** → Выбирает сумму пополнения
3. **Оплата** → Выбирает способ оплаты
4. **Почта** → Указывает почту от Steam
5. **Код** → Получает код с почты и отправляет боту
6. **Готово** → Заказ выполнен!

## 🔧 Администрирование

### Админ панель (`/admin-panel`):
- 📊 Статистика магазина
- 📦 Управление заказами
- 🎁 Управление промокодами
- 👥 Пользователи
- 🔄 Переключение в режим клиента

### Процесс подтверждения заказа:
1. Клиент создаёт заказ → статус `pending`
2. Админ получает уведомление
3. Админ подтверждает → статус `paid`
4. Клиент отправляет код
5. Админ завершает → статус `completed`

## 🛠️ Установка

```bash
# Сборка Docker
docker-compose build telegram-bot

# Запуск
docker-compose up -d telegram-bot

# Просмотр логов
docker logs -f neymaryshop_telegram_bot
```
