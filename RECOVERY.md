## 🚀 **Быстрое восстановление:**

### **1. Установите Git (если нет):**
- Скачайте: https://git-scm.com/download/win
- Установите и перезапустите терминал

### **2. Восстановите все файлы:**
```bash
git restore .
git status
```

### **3. Если не сработало, попробуйте:**
```bash
git checkout HEAD -- .
git reset --hard HEAD
```

## 🆘 **Если Git не работает:**

### **Вариант А: Github Desktop**
1. Установите: https://desktop.github.com/
2. Откройте папку проекта
3. Right-click → "Restore changes"

### **Вариант Б: VSCode**
1. Откройте папку в VSCode
2. Ctrl+Shift+G (вкладка Git)
3. Right-click на измененных файлах → "Discard Changes"
